# Sistema-Semantico-Academico
Un sistema para gestionar la información de una universidad: alumnos, profesores, materias, carreras, grupos, calificaciones y kardex.

Módulos:
- 👩‍🎓 Alumnos
- 👨‍🏫 Profesores
- 📚 Materias
- 🎓 Carreras
- 🏫 Grupos
- 📊 Calificaciones
- 📋 Kardex
- 📅 Horarios
- 📈 Dashboard académico

Tecnologías:
- XML → almacenar información académica.
- DTD → validar la estructura básica.
- XSD → validar tipos, restricciones y relaciones estructurales.
- XSL/XSLT → transformar XML en páginas HTML.
- RDF → representar las relaciones semánticas.
- Dashboard → visualizar estadísticas.
